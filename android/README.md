# Android Ground Station

Status: not yet implemented — planned for M6 (Android Ground Station App). Will be a native Kotlin, Jetpack Compose, single-activity MVVM app.

The actual Android Studio project (Gradle wrapper, module structure under `app/src/main/java/.../{video,control,telemetry,comms}`) will be generated when M6 starts, once M5's WebRTC/WebSocket comms layer exists on the Pi side to build the app's first screen (live video) against.
